Demo 6: WebMessagePort

原理：使用 WebMessagePort API（API 23+）进行安全的双向消息传递。与 @JavascriptInterface 不同，不暴露 Java 对象给 JS，而是通过 MessagePort 通道交换 WebMessage 对象。
步骤：
1. Android 调用 createWebMessageChannel() 创建端口对
2. 端口[0] 留在 Android 端，端口[1] 通过 postWebMessage() 传给 JS
3. 双方通过 port.postMessage() / port.onmessage 通信
